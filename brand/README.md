# Shamrock Transportation logo (Ellie's pick, 2026-10-15)

The engraved line shamrock: one fine outline of three heart leaves and a stem, a vein in each leaf, the stem tucked behind the lower leaf. These files are the exact drawing. Copy them byte for byte.

- `shamrock-deep-green.svg` / `shamrock-ivory.svg`: for display sizes, about 64px and up.
- `shamrock-small-*.svg`: for 16 to 48px only (a heavier line so it survives). `../favicon.svg` is the tab icon.
- To color it to a palette, inline the SVG and change only the `color` attribute. Everything is drawn in currentColor.

Don't: change the line weights, thicken the veins, add a fill, glow or shadow, or put it inside a frame, badge or tile on the page. Only the favicon and home-screen icon sit on a rounded square.
